Skill jp-web-design の各セクションを、そのまま実装した見本です。色は「意味」にしか使いません。

カラートークン — プライマリ + 差し色1色 + グレースケール

60% = 白・極薄グレーの地 / 30% = 文字・罫線 / 10% = 操作(brand)と結果(accent)。差し色は1色まで・1画面の色相は3つまで。企業カラー指定時は brand にプライマリ、accent に補色系1色(緑系プライマリ→オレンジ等)を割り当て、残りはグレースケールのまま。黒背景は絶対に作らない。

テーブル — 数値はExcel基準

セルは「生数値+3桁カンマ」のみ。単位は列ヘッダーへ(1列1単位)。右揃え+等幅数字+欧文フォント。桁の圧縮はヘッダーの単位変更(円→万円→百万円)で行い、セル側で概数に丸めない。SPでは主要3項目のカードに組み替える。
