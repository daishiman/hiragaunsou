平賀運送 車両別収支アプリに届いている改善要望のうち、いま渡されているものを一覧で見る。

## 手順

1. アプリのフォルダで次を実行する。

   ```
   pnpm run improvement -- list
   ```

2. 返ってきた一覧をそのまま利用者へ示し、どれから直すか選んでもらう。
   一覧には id・優先度・種類・見出しだけが載っている。中身は取得したときに読む。

## 守ること

- 鍵 (トークン) を自分で読まない・探さない・表示しない。コマンドが自分で解決する。
- 接続先の既定は手元のアプリ (`http://localhost:8787`)。
  「渡した要望が出てこない」と言われても、本番を見に行く設定を勝手に足さない。
  本番を見る必要があるなら、それは利用者に判断してもらう。
- 上のコマンドが「鍵の置き場所が見つかりません」と言った場合は、
  出てきた案内文をそのまま利用者へ渡す。こちらで鍵を用意しようとしない。
