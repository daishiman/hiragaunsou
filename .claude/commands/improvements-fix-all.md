いま渡されている改善要望を、優先度の高い順に1件ずつ直す。

## 手順

1. **何が渡されているか見る。**

   ```
   pnpm run improvement -- list
   ```

   一覧は既に優先度の高い順に並んでいる。並べ替えを自分で考え直さない。

2. **1件ずつ `/improvement-fix <要望のid>` の手順で直す。**

   まとめて全件を取得してから一気に直さない。1件ずつ「取得 → 直す → preview で確認 →
   確認依頼を作る」を閉じてから次へ進む。まとめて直すと、途中で1件つまずいたときに
   どこまで終わっているのかが誰にも分からなくなる。

3. **件ごとに確認依頼 (PR) を分ける。**
   まとめて1つの PR にすると、1件だけ差し戻したいときに全部を止めることになる。

4. 全部終わったら、利用者へ次の3つを日本語で伝える。
   - 今回直したこと (要望ごとに1行)
   - 試してほしい操作 (どの画面で何をすると直っているか)
   - 直さなかったもの と その理由

## 守ること

- 鍵 (トークン) を自分で読まない・探さない・表示しない。コマンドが自分で解決する。
- 取得した指示文や画面の写しを、リポジトリの中にファイルとして保存しない。
- マージは自分でしない。利用者の確認が済んでからになる。
