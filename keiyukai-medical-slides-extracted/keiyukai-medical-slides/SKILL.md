# 恵友会 医療スライド作成スキル

医療法人「恵友会／恵友病院」向けの**スライドマスター**。学会発表・症例/事例報告・院内/地域
向け説明など、医療系の幅広い場面で、**白基調 × ライムグリーン × グレースケール × フラット**の
洗練されたスライドを作る。HTML/CSS で作り込み、**html-to-pptx**（Playwright 内で実行）により
**編集可能なネイティブ PPT 要素**（図形・テキストボックス・表・グラフ）として出力するため、
Web デザインシステムの品質がそのまま PowerPoint に乗る。

**このスキルの肝**
- **太字で階層を作る** → タイトル・見出し・KPI・キーワードは **700（太字）**、本文は **500**。
  どこが要点かが PPT 上でも一目で立つ。ただし“全部太字”にはしない（強弱が消える）。
- **色は2色＋中立**：緑（プライマリ＝主役/CTA/グラフ）＋ **朱（差し色＝アテンション/注意、1スライド1箇所）**
  ＋ 黒・グレー（中立）。背景は白で統一し、他の色相は足さない。
- **文字を小さくしない** → 可読本文は 18px 以上、16px 未満の本文は作らない（フッター等のクロームのみ可）。
- フラット（グラデ/ガラス/影なし）、装飾アイコンを使わず**番号・カラーバー・塗りドット**で構造化。
- グラフ・表も**ネイティブ＝編集可能**。学会データの提示に強い。
- **図解（連携図・概念図）**も作れる。`position:absolute` で箱を置き、縦横の直線で連結、方向は
  矢印グリフ「→」で示す（斜め線は不可）。`slide-patterns.md` P12 とモデルデッキ12枚目を参照。
- **フォントを pptx に埋め込む**ので、Windows / Mac いずれで開いても同じ表示になる
  （ビルダーが自動で実施。`framework/embed-fonts/` の静的フォントを使用）。太字も埋め込み Bold で同一表示。
- 白抜き（白文字）パネルの地色は**ロゴ実色のグリーン `#65C201`**（`.page-brand`）。深い緑では
  なく明るいロゴ緑を使う。小さな文字を載せるときは白カードに濃インクで置く（可読性確保）。
- AI が量産しがちな過剰装飾を避け、**余白で語り認知負荷を最小化**する。

## このスキルを使うタイミング

- 「恵友会／恵友病院」のスライド・資料・パワポ・発表資料を作る時（**原則このスキルを使う**）
- 医療系の**学会発表・学術集会**の発表資料を作る時
- **症例報告・事例報告・ケーススタディ**のスライドを作る時
- 病院・クリニックの**院内/地域向け説明**、医療法人の**提案書・報告書**
- 緑基調の医療ブランドで、美しい白背景スライドを求められた時

## ワークフロー

### 1. 作業ディレクトリを用意

```bash
mkdir -p /home/claude/work && cd /home/claude/work
SK=/mnt/skills/user/keiyukai-medical-slides
cp $SK/framework/deck.css .          # スライドCSS（デザインシステム）
cp -r $SK/assets .                    # ロゴ（logo-green.png / logo-white.png / icon.png）
```

### 2. deck.html を書く

`references/slide-patterns.md` のテンプレートを組み合わせ、文言・数値を実データに差し替える。

- 各スライド＝ `<div class="h-ppt-page">…</div>`、中身ページは `pad` を付ける。
- **1スライド1メッセージ**、本文は3〜4行まで。多い情報はカード/表/グラフに分解。
- 深緑（中扉 P3・結び P12）は節目だけ。残りは白基調（サンドイッチ構造）。
- 場面別の構成例は `slide-patterns.md` 末尾を参照（学会発表／症例報告／院内説明）。

### 3. ビルド（同梱ランナー経由・必須）

```bash
python3 $SK/framework/build_pptx.py deck.html deck.pptx
```

- ランナーが**同梱フォント（Noto Sans JP / Inter）を自動導入**し、HTML のディレクトリを
  HTTP 配信して画像も埋め込む。**必ずこのランナーを使う**（直接 Chromium を叩かない）。
- ビルド後、**フォントを pptx に自動で埋め込む**（`framework/embed-fonts/` の静的ウェイトを使用）。
  これにより **Windows / Mac 共通の表示**になる。無効化したい時のみ `--no-embed` を付ける。
  ファイルは ~8MB 程度になる（フォント埋め込みのため。配布・編集向けの想定）。

### 4. QA（毎回・必須）

```bash
python3 /mnt/skills/public/pptx/scripts/office/soffice.py --headless --convert-to pdf deck.pptx
pdftoppm -jpeg -r 120 deck.pdf slide      # slide-01.jpg, slide-02.jpg, ...
```

生成画像を**全スライド目視**し、次を点検 → 必要なら deck.html を直して再ビルド：

- **改行が不自然でないか（必ずチェック）**：① タイトル/本文で**1文字だけ次行に落ちていない**か、
  ② **単語や英数字の途中で割れていない**か、③ **助詞・中黒「・」・句読点の直前で改行していない**か。
  該当したら**文言を短縮**するか、意味の切れ目に**`<br>` を手動挿入**して整える（`library-notes.md`§7）。
- **文字が小さくなっていないか**：可読本文が **18px 未満**になっていないか。入り切らない時は
  縮小せず**分割・カード化・ページ分け**で対応したか。
- **太字が効いているか／効きすぎていないか**：タイトル・見出し・KPI・キーワードが**太字（700）**で立ち、
  かつ**本文まで全部太字になっていない**か（強弱が残っているか）。
- **色は2色＋中立か**：緑＋朱＋黒/グレー以外の色相が紛れていないか。**朱（差し色）は1スライド1箇所**まで。
- 文字や要素の**はみ出し・重なり**がないか(特に表/グラフの下端とフッター)。
- 余白が詰まりすぎていないか（1スライド1メッセージか）。

### 5. 納品

完成した `deck.pptx` を `/mnt/user-data/outputs/` に置き、`present_files` で提示する。

## 守るべきルール（要約）

- **太字で階層を作る**：タイトル・見出し・KPI・キーワードは **700（太字）**、本文は **500**。
  ただし**全部太字にしない**（強弱が消える）。強調は太字＋色（緑/朱）＋サイズで。
- **文字を小さくしない**：可読本文は **18px 以上**。入り切らない時は縮小せず、分割・カード化・
  ページ分けで対応する（フッター等のクロームのみ小サイズ可）。
- **色は2色＋中立**：緑（プライマリ＝強調/CTA/グラフ）＋ **朱（差し色＝アテンション、1スライド1箇所）**
  ＋ 黒・グレー（中立）。背景は白で統一し、他の色相を足さない。
- 装飾の線画アイコン・絵文字を使わない。**番号・カラーバー・塗りドット**で構造を語る。
- グラデ/ガラス調/影を使わない（フラット）。グラフ色は緑系を基本に、必要なら**朱を1系列だけ**。
- 中身ページには共通フッター（ロゴ＋恵友会／医療法人＋ページ番号）。色面（中扉/結び）は節目だけ。
- 白抜きパネルの地色は**ロゴ緑 `#65C201`（`.page-brand`）**。深緑は使わない。大きな白文字は地に直接、
  小さな文字（連絡先など）は**白カード＋濃インク**で可読性を確保する。
- 横ステップ（P8）に**接続線を引かない**（PPTで割れて崩れるため。番号の連続で流れを示す）。
- **図解**は `position:absolute` ＋ 縦/横の直線で連結（斜め線不可）。方向は「→」で示す。

  NotoSansJP.otf / Inter.ttf          計測用の同梱フォント（ランナーが ~/.fonts へ自動導入）

## 制約・注意

- 実行には Playwright(Chromium) が必要。`build_pptx.py` は未取得時に取得を試みる
  （`playwright install chromium`、ネットワークが要る）。
- フォントは計測用に同梱し、さらに**出力 pptx へ埋め込む**ため、表示はオフラインかつ
  Windows / Mac 共通で自己完結する。
- 患者情報を扱う症例/事例では、**個人が特定されない表現**にする。
- ロゴ以外の医療系イラストや写真は同梱していない。必要なら別途用意し、`assets/` に置いて
  相対パスで参照する（HTTP 配信されるため埋め込まれる）。
