# カラー規律の詳細 — プライマリ + 差し色1色 + グレースケール

SKILL.md「カラー規律」の詳細版。60-30-10 の比率表と絶対ルールは SKILL.md 側にある。ここには**補色選定表・トーン調整・ティント面の使い分け**を置く。

## 1. ブランドカラー適用(企業カラーを指定されたとき)

**`--brand` にプライマリカラー、`--accent` に補色系の差し色を1色**割り当て、残りはグレースケールのまま。役割の割り当ては変えない。

| プライマリ(指定色) | 差し色の初期候補 | 備考 |
|---|---|---|
| ネイビー・青系(デフォルト) | オレンジ `#e8590c` | 実績のある既定ペア |
| **深めの水色・シアン系**(実案件で頻出) | コーラルオレンジ `#e8590c` / 淡めのローズ `#e57a9e` | 「真っ青」より深めの水色 `#0e7490` 前後がブランド色になりがち |
| 緑・ライトグリーン | ソフトアンバー `#e0973f` | 緑系accentは成功色と衝突するので不可 |
| ティール・青緑 | コーラル `#e8590c` 寄り | |
| 赤・ワインレッド | チャコール+brand側を赤に | 赤×緑の補色ペアは状態色と衝突するため使わない |
| 紫 | ソフトアンバー `#e0973f` | |
| ピンクを差したいとき | 淡めのローズ `#e57a9e` | 鮮ピンク(`#d6336c`級)はきつい |
| オレンジ・暖色 | ネイビー `#1d63be` 系 | brand/accentの役割を逆に持たせない(操作=指定色) |
| 黒・モノクロ指定 | 青 `#1d63be` を操作色に | 「黒がブランド」でも黒背景パネルは作らない |

> **差し色は淡め・柔らかめに倒す**。CTAとキー数字に使う分には柔らかいトーンでも十分立つ。強い彩度の差し色は画面全体をきつくする(青×オレンジ `#e8590c` は実績上OK、それ以外は一段淡く)。

- **原色・蛍光色をそのまま使わない**。はっきりしすぎる色は視覚的にきつい。純青 `#0000ff` ではなく `#1d63be`、純シアンではなく `#0e7490` のように、**彩度を一段落としたトーン**に調整してから採用する。
- 差し色はプライマリと**彩度・明度のトーンを揃える**(片方だけ蛍光にしない)。
- 白文字を載せる色はコントラスト比4.5:1以上を確認する。足りなければ `-deep` 側を濃くする。
- danger(`#d93025`)はブランドが何色でも変えない(意味色は共通)。
- ブランド色を差し替えたら **soft/mist ティントも同じ色相から作り直す**(青のティントのまま緑ブランドにしない)。

## 2. プライマリの「面」 — 白一色の単調を避ける(ただしコンテンツで使い分ける)

白背景基調は守りつつ、プライマリの気配が全くない画面は単調でブランドの体温が伝わらない。**ただし安易に全ページをティントで塗らない。地の色は「その画面の主役」で決める**:

| 画面の主役 | 地の選択 | 理由 |
|---|---|---|
| 数字・表・長時間の作業(業務一覧・帳票・管理画面) | 白〜無彩の極薄グレー | データが主役。地の色は視覚ノイズになる |
| 行動・感情(toCホーム・結果画面・LP・完了画面) | `--brand-mist`(brandの極薄ティント) | 温度と個性が出る。白カードが浮き立つ |
| 1画面の中で混在 | 地は静かに、**主役の面だけ**ティント | 全部塗ると主役が消える |

使ってよい面(モードA):

| 面 | 使う色 | 用途 |
|---|---|---|
| ページ地(toC・結果系のみ) | `--brand-mist` | 白カードを立たせる地 |
| ヒーロー・結果カードの面 | 白→`--brand-soft` の微グラデ or brand-soft単色 | 視覚的主役の面。**1画面1箇所まで** |
| アイコンチップ・番号チップ | brand-soft地 + brand文字/アイコン | 文字だけの並びに視覚のアンカーを作る |
| 選択状態・アクティブタブ | brand-soft地 + brand-deep文字 | 既存ルール通り |

- ティントは**低彩度・高明度に限る**(本文の可読性を落とさない)。彩度の高いbrandベタ塗りの面は操作要素(ボタン・バー)だけ(モードBは `mode-b-pop.md` の基準に従う)。
- accentの「2箇所ルール」・1画面の色相3つルールは**ティントを増やしても不変**。
