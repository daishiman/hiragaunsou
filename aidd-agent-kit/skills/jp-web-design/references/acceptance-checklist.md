# 検収チェックリスト

UI実装の検収に使う全項目。実装完了の判定に使う。体験面(デフォルト・一括操作・正直なUI・エラー回復)の検収は Skill `ux-design` のチェックリストを併用する。

- [ ] 色はプライマリ+差し色1+グレースケールに収まっているか。accentは2箇所以下、1画面の色相は3つ以下か。
- [ ] 黒/ダーク背景のパネルを作っていないか。ダークモードを勝手に実装していないか。
- [ ] **白一色で単調になっていないか**。ページ地はbrand-mist、主役面・チップ・選択状態にプライマリの気配があるか(ただしティント面は1画面1箇所)。
- [ ] 説明文の連なりを視覚要素(数字・サイズ差・チップ・面)に置き換えたか。文字文字しい画面が残っていないか。
- [ ] 「濃く太い数字=変わる値」の文法が全画面で統一されているか(値/ラベル/単位の描き分け)。
- [ ] 1画面に視覚的主役が1つ決まっており、主役:本文のサイズ比が2.5倍以上あるか。同格要素のサイズは揃っているか。
- [ ] 初見でマニュアルなしに最頻タスクが完了できるか。押せないものに押せる見た目が付いていないか。
- [ ] ヘッダーのアプリ名クリックでホームに戻るか。
- [ ] **375 / 768 / 1280 / 1600px の4幅を実測**し、「1文字だけ改行」「1個だけ折返し」「途中折返し」「ワイドの間延び」がないか。
- [ ] SPで情報削減(カード化・折りたたみ・上位N件)が入っているか。全情報を縮小して詰め込んでいないか。
- [ ] テーブルの数値は「生数値+カンマ・右揃え・単位は列ヘッダー・1列1単位」か。数字が和文フォントで描画されていないか(`--font-num`)。主数字のカンマは縮小(`.num-sep`)・通貨記号は単位扱い(`.currency`)か。
- [ ] 12px未満の本文・補足がないか。補足文は1行以内か(長い説明はplaceholder・ラベル・開示へ移したか)。
- [ ] 不可逆な送信がEnter即送信になっていないか。ショートカットはキーキャップUIで表示されているか。
- [ ] 使い回す部品の切替がコンテナクエリで書かれているか(部品にメディアクエリを直書きしていないか)。
- [ ] バーチャートは `components.md` の3条件を満たすものだけか。比率を恣意スケールで描いていないか。
- [ ] カード左端の色帯を使っていないか(禁止。分類色はチップ/ドット/バーで)。
- [ ] フォーム: ラベル上置き・エラーが項目の場所で出る・必須が視覚+テキストで分かるか。
- [ ] すべての部品に hover / focus-visible / disabled / loading / error / empty があるか。
- [ ] モーダルにフォーカストラップ、エラートーストに次のアクションがあるか。すべてのアニメーションが reduced-motion で止まるか。
- [ ] **動的パスを実際に操作して検証したか**: 選択→件数連動 / モーダル開閉(ESC・フォーカス復帰) / 実行中→部分成功→再試行 / 下書き保存→復元→破棄 / Enter・⌘+Enter。静的スクショだけで検収しない。
- [ ] 比喩コピー・多色アイコン・絵文字が混入していないか。表示している数字はすべて本物の計算結果か。
