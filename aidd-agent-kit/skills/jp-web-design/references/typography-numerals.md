# タイポグラフィ・数値表記・日本語組版

タイポグラフィ・数値表記・日本語組版の全ルール。メリハリ(視覚的主役)・補足文の規律・Excel基準の数値・アフォーダンス・折返し禁則。

## 1. メリハリ(視覚的主役) — 同格をダイナミックに分ける

**全部同じフォント・太さ・大きさの画面は、どこから見ればいいか分からない。**

- **1画面に視覚的主役を1つ**決める(結果画面=主数字 / 入力画面=ページタイトルと主要CTA / 一覧=要対応の件数など)。主役はサイズ・太さで圧倒的に立たせ、それ以外は静かに保つ。
- **主役と本文のサイズ比は2.5倍以上**(例: 本文14px ↔ 主数字44px)。中途半端な1.2倍差はメリハリではなくノイズ。
- 階層は**サイズと太さの2軸**で最低2段差を付ける(例: 主役 44px/bold → 見出し 13px/bold → 本文 14px/normal → 補足 12px/muted)。
- **同格の要素はサイズを揃える**(並列カードの見出し同士など)。メリハリは「主役を1つ立てる」ことで作る。全要素を少しずつ大きくしない(フォン・レストルフ効果: 目立つのは1つだから目立つ)。
- ファーストビュー(スクロールなし)に「主役 + 次に取るべき行動(主要CTA)」が入るようにレイアウトする。
- **説明で埋めない — ダイナミックに解く(文字文字しい画面の禁止)**。同じサイズの文字がびっしり並んだ画面は読む前に疲れる。説明文を足したくなったら、先にこの順で視覚要素に置き換えられないか試す:
  1. **数字を主役化する**(文で書かず、大きな数字+短いラベル)
  2. **サイズ・太さの差**で構造を見せる(見出し文を長くするのではなく、キーワードを立てる)
  3. **チップ・番号・アイコンチップ**(brand-soft地)で文字列の並びに視覚のアンカーを置く
  4. **面の分割**(カード・ストリップ)で段落の代わりをする
  文字を減らした分だけメリハリは強くなる。下記「補足文の規律」とセットで適用する。

| 用途 | サイズ | 太さ |
|---|---|---|
| ページ主数字(結果)= 主役 | `text-4xl`〜`5xl`(36〜44px) | bold・accent・`--font-num` |
| ページタイトル | `text-lg`〜`xl`(18〜20px) | bold |
| セクション見出し | `text-sm`(13px) | 太字だが小さく静かに |
| 本文 | `text-sm`(14px) | normal |
| 補足・ラベル | 12px(SPは13px推奨)`text-ink-muted` | normal |

> 見出しを「大きく・色付き」で目立たせない。主役は中身(数字・事実)。

## 2. 補足文の規律(小さいグレーの長文を作らない)

「グレー・小さい・長い」の三重苦は読まれない上に見にくい。**文字を小さくして詰め込むのではなく、文字数が少なくて済む構造にする。**

- 補足・説明文は**1行(全角25〜30字)以内**。2行を超えたら文章を削るのではなく置き場所を変える: 例示は placeholder へ / 条件はラベルの語に含める / 詳細は `<details>` の開示へ。
- コピーは**体言止めの短文**でよい(「貼り付けやドラッグ&ドロップでも」)。丁寧語の冗長化(「〜することができます」→「〜できます」)を刈る。
- **最小フォントサイズ 12px**。11px以下の本文・補足を作らない(チップ・キーキャップ等のUI部品ラベルのみ11pxまで許容)。SPでは補足も13pxを推奨。
- 説明が必要になったら、まず「説明なしで分かるUI(§4 アフォーダンス)にできないか」を疑う。placeholder・デフォルト値・ラベルで挙動を予告できれば説明文は要らない。

## 3. 数値の表記 — Excel基準・シャープに

**数字を和文フォントで描画するとボサッと見える。数字は必ず欧文フォントで、表記はExcelに貼って通る形を基準にする。**

```css
.num {
  font-family: var(--font-num);          /* Helvetica/SF系。和文フォントに落とさない */
  font-variant-numeric: tabular-nums;    /* 等幅数字 */
  letter-spacing: -0.02em;               /* 本文サイズの数字は詰めてシャープに */
  white-space: nowrap;
}
.num-display { /* 主数字・KPI用 */
  font-family: var(--font-num);
  font-variant-numeric: tabular-nums;
  letter-spacing: -0.015em;              /* 大型数字は詰めすぎない(-0.03emは窮屈。微妙に空ける) */
  font-weight: 700;
}
/* 大型数字の桁区切りは脇役に落とす(数字が主役、カンマは読みの補助) */
.num-sep { font-size: 0.8em; font-weight: 400; }
/* 通貨記号は「単位」扱い: 数字より小さく・微小な間隔を空ける */
.currency { font-size: 62%; font-weight: 600; margin-right: 0.15em; letter-spacing: 0; }
```

- **主数字・KPIなど大型表示のカンマは `<span class="num-sep">,</span>` でサイズを一段下げる**(0.8em+細字)。**透明度では調整しない**(にじんで見える)。テーブルの通常サイズのカンマはそのまま(Excel互換の読み取りが優先)。
- **通貨記号(¥・$)は単位・助数詞と同じ扱い**: 数字=変数、記号=固定ラベル。`<span class="currency">¥</span>` で数字の約62%サイズに落とし、数字との間に `0.15em` の間隔を空けて「どこからが値か」を見分けられるようにする。単位(万円・通・件)も同様に約58%サイズ(`.unit`)。
- 実装はフォーマッタ側で一括置換: `formatted.replace(/,/g, '<span class="num-sep">,</span>')`。

### 値(変数)とラベル(固定)の描き分け — 「濃く太い数字=変わる値」の文法

画面中のどこが**変数(データによって変わる値)**で、どこが固定の飾りかが一目で分かるように、値のスタイルを全画面で統一する:

| 要素 | スタイル |
|---|---|
| 値(変数) | `.num` / bold / `--ink`(主役ならaccent)— 常に画面で最も濃く太い |
| ラベル(固定) | 12〜13px / `--ink-muted` / normal |
| 単位・通貨記号(固定) | 値の58〜62%サイズ / `.unit` `.currency` |

- この組を崩さない(あるカードでは値が細く、別のカードではラベルが太い、を作らない)。ユーザーは数画面で「濃く太い=データ」という文法を学習する。
- 更新され得る値は `tabular-nums` で**桁が変わっても幅が跳ねない**ようにする。
- 値の更新はカウントアップ(rAF)または背景の一瞬のフラッシュ(brand-soft→透明、400ms)で「変わった」ことを伝える(`motion-a11y.md`)。

### テーブル・KPIの表記規則

- **テーブル/DB系のセルは「生の数値 + 3桁カンマ」のみ**(例: `23,048`)。`Intl.NumberFormat('ja-JP')` で整形。**単位・通貨は列ヘッダーに書く**(「価格(万円)」「金額(円)」「利回り(%)」)。セル内に「2.3億」「9,800万」と単位を混ぜない(**1列1単位**)。
- 桁の圧縮は**列ヘッダーの単位変更**で行う(円→千円→万円→百万円)。セル側で概数に丸めない。
- **ダッシュボードの主数字・KPIは正確な値**を出す(「86通」「18.6%」)。単位・助数詞は数字の50〜60%サイズで小さく添える(`<span class="num-display">86</span><span class="unit">通</span>`)。「約2.3億円」等の概数は本文・補足の文章内でのみ使う。
- 通貨を円単位で出す帳票は `¥12,345,678` 形式(`style: 'currency'`)。
- 数値は右揃え + `.num`。「3億7,116万/円」のような**途中折返しは全幅で禁止**。

## 4. アフォーダンス — マニュアルなしで操作が分かる

- **押せるものは押せる見た目**: ボタンは塗りか罫線+動詞ラベル(`components.md`)。リンクはbrand色。クリック可能なカードは全面クリック+hoverで背景変化+右端に開く方向の記号。
- **押せないものに押せる見た目を与えない**: 静的なバッジ・KPIにhover効果や `cursor: pointer` を付けない。
- **アイコン単独のボタンを作らない**(ラベルを併記する)。例外は閉じる「×」など世界共通の慣習だけで、その場合も `aria-label` 必須。
- hoverでしか出ない操作を作らない(タッチデバイスで発見不能)。行アクションは常時表示するか、明示の「…」メニューに入れる。
- 慣習に従う(ヤコブの法則): 検索は上、主要CTAは右下/右上、戻るは左。独自のジェスチャー・独自配置を発明しない。
- **検収基準: 初見のユーザーがマニュアル・説明なしで最頻タスクを完了できるか。**

## 5. 折返し・整列の禁則

### 折返しプロパティの使い分け(既定を先に決める)

**語の途中で折り返さないことを既定にする。`word-break: break-all` を「はみ出し対策」として漫然と当てない**(日本語も英単語も語の真ん中で割れ、読み速度が落ちる)。

```css
body {
  line-break: strict;          /* 日本語の禁則を厳格に(行頭の 、。」・行末の「 を防ぐ) */
  overflow-wrap: break-word;   /* はみ出す長い連続文字(URL・型番)だけ最終手段で折る */
  word-break: normal;          /* 既定。break-all を全体に当てない */
}

/* flex/grid の中で長いURL等がはみ出すセルだけ、min-content も縮む anywhere を当てる */
.wrap-anywhere { overflow-wrap: anywhere; }
```

| プロパティ | 役割 | 使いどころ |
|---|---|---|
| `line-break: strict` | 日本語の禁則処理の強さ | 本文・見出しの既定 |
| `overflow-wrap: break-word` | **入りきらないときだけ**任意位置で折る | 全体の既定 |
| `overflow-wrap: anywhere` | 同上 + 要素の最小幅も縮む | flex/grid でセルが押し広げられる箇所に限定して付与 |
| `word-break: break-all` | 常に任意位置で折る | 原則使わない。使うのは連続英数字だけを表示する専用要素に限定 |
| `white-space: nowrap` | 折り返さない | 短いラベル・ボタン文言・表ヘッダー・数値(§3のCSS) |

### 禁則

- 見出しは `text-wrap: balance`。分断しやすい語は文節単位で `<span class="inline-block">評価</span>` にして「評/価」の分割を防ぐ。
- **チップ・ボタン群の「1個だけ折返し(孤児)」禁止**。flex-wrap の成り行きに任せず等幅グリッドで:
  4個=`grid-cols-2 sm:grid-cols-4` / 5個=`grid-cols-3 sm:grid-cols-5` / 6個=`grid-cols-3 sm:grid-cols-6`。2択は `grid-cols-2` で横幅いっぱい等幅(3列に置いて左に寄せない)。
- **短いラベル・ボタン文言・表のヘッダーは折り返さない**(`white-space: nowrap`)。禁止した結果はみ出すなら、**文言を短くするか省略表示(`text-overflow: ellipsis` + `title`)にする**。レイアウトを壊すくらいなら文言を削る。
- **単位・記号を行頭・行末に孤立させない**。「円」「件」「%」「〜」が単独で次行に落ちる形にしない。値と単位は同じ `inline-block`(または `nowrap` の `<span>`)に入れる(§3の `.num` は `white-space: nowrap` 済み)。
- **タブ・チップ類を画面幅の成り行きで折り返させない**。等幅グリッド(上記)かコンテナクエリで列数を落とし、「1個だけ落ちる」「1文字だけ落ちる」割れ方を 375/768/1280/1600px のどの幅でも作らない。
- ラベルは列幅に収まる短さに書き直す(「330㎡以内(約100坪)」→「330㎡以内」、補足は説明文へ)。
- JSX内の改行はスペースになる。日本語の連続文は `{'…'}` で1つの文字列にする。

## 6. UXライティング

- 比喩・話し言葉・キャッチーな造語を避け、**誰が読んでも同じ意味になる直接表現**。
- 専門用語は生活の言葉に言い換える(内部計算では正確な用語を使う)。
- ボタンは動詞で終える。1文50字以内。「〜させていただく」禁止。
- エラーコピーは「何が起きたか + 次に何をすればいいか」。
- **表示する数字はすべて実際の計算結果**。偽の緊急性・煽り・confirmshaming 禁止。
