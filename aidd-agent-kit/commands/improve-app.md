app-orchestrator エージェントを**追加開発モード**で起動して、既存アプリに以下の改善を加えてください。

## 依頼内容

$ARGUMENTS

## 実行ルール

- 必ず Agent ツールで `app-orchestrator` サブエージェントを起動すること。自分で直接実装しない。
- エージェントには「追加開発モード(app-orchestrator.md 参照)で進めること」を明示して渡す。
- 依頼内容が空の場合: 既存プロジェクトの `docs/product/backlog.md`(残課題リスト)を読み、上位候補を3つ以内の選択式でユーザーに提示し、選ばれた1件だけをエージェントに渡す。
- 依頼内容に複数の要望が含まれる場合: 分割して一覧にし、「今回はどれから進めますか?」と選択式で確認してから1件ずつ着手する。
- エージェントは追加開発モードの手順0〜6(ブランチ作成→実装→PR→依頼者の了承1回→マージ→デプロイ)で進める。依頼者への確認は「preview で試して問題ないか」の1回だけに抑える。
- エージェント完了後の報告は非エンジニアが読める言葉で書く: 「今回できるようになったこと / 試してほしい操作 / 更新後の残課題リスト / 次の候補」の順にまとめる。git 用語は使わない(app-orchestrator の語彙対応表に従う)。
