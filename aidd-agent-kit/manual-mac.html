バージョン 1.1.0 ／ 所要時間 約5分

このキットは何?

Claude Code(AIがアプリを作ってくれるツール)に、プロの開発ノウハウ集(スキル16個) と 開発を最初から最後まで自動で進める司令塔(エージェント) を追加するキットです。

インストールすると、Claude Code に

/build-app 社員の勤怠を管理するアプリを作って

と一言頼むだけで、要件の整理 → デザイン → 開発 → 公開 → 品質チェックまでを、決められた手順で自動的に進めてくれるようになります。

事前に必要なもの

必要なもの確認方法
Claude Code がインストールされた Macアプリ一覧に「Claude Code」がある(なければ社内のIT担当者にご相談ください)
Claude へのサインインClaude Code を開いてチャットが使える状態になっている
重要

インストーラーは Claude Code の設定フォルダ(~/.claude)に書き込みます。Claude Code を一度も起動していないとこのフォルダが存在せず、インストールは中断されます。先に Claude Code を起動しておいてください。

インストール手順

1

ZIPファイルを展開する

  1. 受け取った aidd-agent-kit.zip を ダブルクリック します。
  2. 同じ場所に aidd-agent-kit というフォルダができます。
  3. そのフォルダを開きます。
2

インストーラーをダブルクリックする

  1. フォルダの中の install-mac.command をダブルクリックします。
  2. 黒い画面(ターミナル)が開き、自動でインストールが進みます。
  3. 「インストールが完了しました!」 と表示されたら成功です。Enterキーを押して画面を閉じてください。
「開発元を検証できないため開けません」と表示されたら
  1. install-mac.command を 右クリック(または2本指クリック) して 「開く」 を選びます。
  2. 確認画面が出たら 「開く」 をクリックします。

それでも開けない場合(新しいmacOS):

  1. アップルメニュー → システム設定 → プライバシーとセキュリティ を開きます。
  2. 下の方にある 「"install-mac.command"は開発元を確認できないため…」 の右の 「このまま開く」 をクリックします。
  3. もう一度ダブルクリックします。
3

動作確認する

  1. Claude Code を 一度終了して、起動し直します(Command + Q で完全に終了してください)。
  2. チャット欄に半角で /build-app と入力します。
  3. 入力候補に build-app が表示されればインストール成功です。

使い方

基本の使い方

チャット欄に /build-app に続けて、作りたいものを普通の言葉で書くだけです。

/build-app 会議室の予約アプリ。社員だけが使える。Googleアカウントでログイン。

上手に頼むコツ

次の3点を書くと、AIが迷わず一発で作ってくれます。

  1. 誰が使うか(例: 社員だけ / 取引先も / 誰でも)
  2. 何ができるか(例: 予約できる、一覧が見られる、承認できる)
  3. 公開範囲(例: 社内限定 / ログインが必要 / 一般公開)

コマンドを使わなくてもOK

普通に「在庫管理のアプリを作りたい」と話しかけるだけでも、自動的にこのエージェントが動きます。確実に動かしたいときは /build-app を使ってください。

うまくいかないとき

Q1. インストーラーがどうしても開けない

手動でコピーする方法があります。

  1. Finder を開き、メニューの 移動 → フォルダへ移動… を選びます(キーボードで Command + Shift + G でも開けます)。次に ~/.claude と入力して Enter を押します。
    • 「見つかりません」と出た場合は、Claude Code を一度起動してから再度試してください。
  2. ZIPを展開した aidd-agent-kit フォルダの中の skills・agents・commands の3フォルダの中身を、.claude の同じ名前のフォルダの中へそれぞれコピーします(同名フォルダがなければそのままコピーで作成)。
Q2. /build-app が候補に出てこない
  • Claude Code を完全に終了して起動し直してください。追加した内容は起動時に読み込まれます。
  • 新しいチャット(新しいセッション)を開いてから入力してください。
Q3. 「インストールを確認できませんでした」と表示された

画面に入らなかったものの一覧が表示されます。その内容を控えたうえで、次をお試しください。

  • ZIPを展開してできた aidd-agent-kit フォルダの中の install-mac.command を実行しているか確認してください(ZIPの中から直接実行すると失敗します)。
  • 解決しない場合は Q1 の手動コピーをお試しください。
Q4. 「~/.claude が見つかりません」と表示された

Claude Code をまだ一度も起動していない状態です。

  1. Claude Code を起動し、サインインしてチャットが使える状態にします。
  2. Claude Code はそのままでも構いませんので、もう一度インストーラーをダブルクリックします。
Q5. 「別の場所への『近道(リンク)』になっています」と表示された

.claude の中のフォルダが、別の場所を指すリンクとして設定されています。このままコピーすると、まったく関係のないフォルダの中身が書き換えられてしまうため、インストーラーが安全のために処理を止めました。

心当たりがない場合は、この画面のまま導入支援の担当者にお見せください。

ご自身で設定された方は、画面に表示されたコマンドでリンクを一時的に退避してから、もう一度インストーラーを実行してください。

Q6. 「以前のファイルは次の場所に保存してあります」と表示された

.claude に既に同じ名前のファイルがあったため、上書きする前に自動でバックアップしたという意味です。インストール自体は成功しています。

~/.claude/backup-20260726-143000/

元に戻したいときは、このフォルダの中身を元の場所へ戻してください。不要になったら、フォルダごと削除して構いません。

インストールされるものの一覧

すべて ~/.claude フォルダの中に入ります。Claude Code の設定ファイルや、他のアプリには影響しません。

同じ名前のファイルがあった場合

そのファイルは上書きされます。ただし上書き前に backup-(日時) フォルダへ自動で退避されるので、元に戻せます。

更新・アンインストール

更新するとき

新しいバージョンを受け取ったら、STEP 1 から同じ手順を繰り返すだけです。古いファイルは自動でバックアップされてから置き換わります。更新後は Claude Code を再起動してください。

アンインストールしたいとき

Finder で ~/.claude を開き(Command + Shift + G → ~/.claude)、次を削除します。

  1. skills フォルダの中の、上の表にある16個のフォルダ
  2. agents フォルダの中の app-orchestrator.md
  3. commands フォルダの中の build-app.md
注意

skills・agents・commands フォルダ自体は削除しないでください。Claude Code が使う他のファイルが入っている場合があります。

インストール時に作られた backup-(日時) フォルダが残っている場合、その中に元のファイルが入っています。必要なら戻したうえで、フォルダごと削除してください。

管理者の方へ(セットアップ後の運用に必要なもの)

エージェントがアプリをインターネットに公開するところまで自動で行うため、利用する環境によって以下が必要です。非エンジニアの方は、導入支援の担当者にご相談ください。

  • Claude の有料プラン(Claude Code が利用できるプラン)
  • Cloudflare アカウント(アプリの公開先。無料プランで開始可能)と wrangler login によるログイン
  • Googleログイン機能を使う場合: Google Cloud の OAuth 設定(手順はスキル内に日本語で収録済み)
  • AI機能を使う場合: OpenAI / Anthropic 等の APIキー
