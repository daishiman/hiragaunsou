# Improve app

1. `$improve-app` と同じメッセージに書かれた内容を今回の改善依頼として扱う。
2. 依頼が空なら `docs/product/backlog.md` を読み、上位候補を3件以内で示して1件を選んでもらう。
3. 複数要望が含まれる場合は分割し、今回進める1件だけを選んでもらう。
4. `app_orchestrator` カスタムエージェントへ「追加開発モードで進める」と明示して委譲し、完了まで待つ。カスタムエージェントを利用できないクライアントでは、現在のスレッドで `$app-orchestrator` を使用して追加開発モードを完遂する。後者は互換フォールバックであり、手順を省略してよいという意味ではない。
5. 追加開発モードの手順0〜6（ブランチ作成→実装→PR→依頼者の了承1回→マージ→デプロイ）で進める。依頼者への確認は「previewで試して問題ないか」の1回だけに抑える。
6. 最終報告は、今回できるようになったこと、試してほしい操作、更新後の残課題、次の候補の順で、非エンジニア向けの言葉で書く。git用語は使わず、`app-orchestrator` の語彙対応表に従う。
