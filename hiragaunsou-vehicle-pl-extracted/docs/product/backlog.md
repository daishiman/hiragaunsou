# 残課題リスト

「やらないこと」ではなく「順番を後にしたこと」。次に何から着手するかは依頼者が選ぶ。

書式: `- [分類] 内容 — 後回しにした理由`

## 月次収支表の確認作業まわり (2026-08-08 追加)

- [機能] セル単位の直しの履歴画面 — 誰がいつ何を直したかは操作の履歴に残っており追えるので、専用画面は使いたい場面が出てからでよい
- [UX] 複数セルのコピー&貼り付け・範囲選択 — 1件ずつ直しながら判断する作業なので、まとめて貼る場面がまだ無い
- [UX] 「この車両の指摘をまとめて確認済みにする」一括操作 — 指摘ごとに判断してほしいため、まずは1件ずつで運用し、手間が問題になってから足す
- [UX] 乗務員数・賞与(月額)を収支表の上で直す — 収支表に列が無い項目のため、従来どおり車両ごとの詳細画面から直す
- [性能] 収支表の差分再計算 — キリン協力金の按分やトレーラの吸収で1台の直しが他の行に波及するため、差分計算は表全体と同じ知識が必要になる。作り直しを呼ぶ回数を1回に減らすことで待ち時間の問題は解けているので、作らない判断
- [UX] 表の行の仮想スクロール(見えている行だけ描く) — 106台では実測で問題が出ていないため、台数が増えてから
- [機能] 確認済みにするときのメモ入力欄 — 保存の仕組みは用意済み(APIはメモを受け取れる)。画面に欄を出すのは、判断理由を残したい要望が出てから

## 確認画面(集中モード)まわり (2026-08-08 追加)

- [UX] 集中モードの中での並べ替え・絞り込み(車両ごと・指摘の種類ごとにまとめて見る) — まずは「要修正 → 要確認 → 参考」の順に1件ずつ通す運用で足りるか確かめてから
- [UX] 同じ種類の指摘をまとめて「このままでOK」にする — 指摘ごとに判断してほしいため、手間が問題になってから足す
- [機能] 確認画面から元の伝票を1枚ずつ見る — いまは元になっている数字(合計)まで表示。伝票そのものの表示は取込画面の作りに手を入れる必要があるため次回
- [UX] 表の上でセルを直接直す使い方の案内 — 慣れた方向けに残してあるが、初めての方が迷わないよう既定では案内していない。使う人が増えたら操作説明を用意する
