# Claude Code でこの改善要望を直す手順

登場するのは2人です。

| 誰 | やること | 回数 |
| --- | --- | --- |
| **システム管理者** | 鍵を1本作って、直す人に渡す | 7日に1回 |
| **直す人（開発者）** | Claude Code に一言頼む | 直すたび |

管理者が毎回コピーして貼る必要は、もうありません。

---

## システム管理者がやること（7日に1回だけ）

### 1. 鍵を作る

1. 管理画面で **改善要望** を開きます。
   <https://hiragaunsou-vehicle-pl.daishimanju.workers.dev/admin/improvements>
2. 渡したい要望に印を付けて **「選んだものを Claude Code に渡す」** を押します。
3. **「Claude Code に渡す文をそのまま読む」** を開いて、外に出て困る文字
   （お客様の名前・電話番号など）が入っていないか確かめてください。
   メールアドレスや電話番号らしいものは自動で伏せてありますが、最後に目で見るのはここだけです。
4. **「この内容で実行する」** を押すと、下に **開発者に渡す案内** が出ます。

### 2. 渡す

出てきた案内を、直す人に渡してください。渡し方は、社内チャットでも口頭でも構いませんが、
**この文字はその人の 1Password に入るもの** です。誰でも見られる場所には貼らないでください。

> この案内はこの画面を閉じると二度と出せません。閉じてしまったら、もう一度1〜2をやり直してください
> （同じ要望を何度渡しても、要望が増えたり二重になったりはしません）。

### 3. 要らなくなったら止める

**「Claude Code に渡した鍵を見る・止める」**
（<https://hiragaunsou-vehicle-pl.daishimanju.workers.dev/admin/improvements/tokens>）
から止められます。止めた瞬間から、その鍵では1件も読めなくなります。

止めるのは、こんなときです。

- 渡した相手が変わった
- 渡した文字を、見せるつもりのない場所に貼ってしまった
- 直す人が「無くした」と言ってきた（**探さずに、止めて作り直してください**）

---

## 直す人がやること

### 最初の1回だけ：鍵を預ける

受け取った案内のとおりに進めます。やることは2つです。

1. 1Password に項目を作り、もらった鍵を保存する
2. アプリのフォルダに `.env.improvement` を作り、**1Password のどこにあるか**だけを書く

```
HGCC_TOKEN="op://保管庫の名前/項目の名前/credential"
```

鍵そのものをこのファイルに書かないでください。書いた鍵は、うっかり保存すると取り消せません
（保存しようとしても、その場で止まる仕掛けは入れてあります）。

### 直すとき：Claude Code に一言

```
/improvements
```

これで、渡された要望の一覧が出ます。1件だけ直すなら `/improvement-fix`、
全部まとめて直すなら `/improvements-fix-all` です。

**Claude に鍵を渡す必要はありません。** 道具が 1Password から自分で取り出して使い、
Claude には要望の中身だけを渡します。鍵を貼ってしまうと会話の履歴に残り、消せません。

### 見に行く先

何も指定しなければ、**手元のアプリ（localhost:8787）** を見ます。
本番の要望を取り込みたいときだけ、`.env.improvement` にもう1行足してください。

```
HGCC_BASE_URL="https://hiragaunsou-vehicle-pl.daishimanju.workers.dev"
```

## 直したあとの流れ（自動で進みます）

| 起きたこと | 要望の状態 |
| --- | --- |
| 指示文を取得した | **対応中** |
| 確認依頼（PR）を作った | **レビュー待ち** |
| 確認依頼がマージされた | **対応済み** |
| 確認依頼を取り下げた | **対応中**に戻る |

管理画面で状態を手で動かす必要はありません。
「見送り」「誤作成」「重複」にした要望だけは、この自動の動きから外れます
（人が理由を書いて脇へ寄せたものを、機械が引き戻さないため）。

## よくあること

**「この鍵は期限が切れています」と出た**
鍵は7日で切れます。管理者に頼んで作り直してもらい、1Password の中身を入れ替えてください。

**「1Password が見つかりません」と出た**
1Password の CLI が入っていない環境です。案内のとおりに入れてください。
どうしても入れられないときは、環境変数 `HGCC_TOKEN` に鍵そのものを入れても動きます
（どちらを使っているかは、実行のたびに1行目に出ます）。

**「この鍵では読めません」と出た**
GitHub Actions 用の鍵を手元に入れてしまっています。その鍵は状態を進めることしかできません。
管理者に、開発者用の鍵を作ってもらってください。

**「この鍵で取得していない要望です」と出た**
指示文を読まずに状態だけ進めようとしています。先に取得してください。

**同じ要望をもう一度渡したい**
そのまま渡し直して問題ありません。内容が変わっていない要望は「変わっていないので何もしません」と
表示され、二重にはなりません。内容を書き足していた場合だけ、新しい版として渡ります。

**渡した要望を取り下げたい**
その要望を「見送り」「誤作成」「重複」にするか、廃棄すると、渡してあった指示文は読めなくなります。

---

## 渡している中身について

- 要望の本文、どの画面か、直す場所の見当、再現手順、裏で出ていたエラー、画面の写しを渡します。
- 画面の写しは24時間だけ開けるURLで渡します。画像を他のサービスに預けることはしません。
- 送った人の氏名とメールアドレスは渡しません（直すのに要らないため）。
- 本文に混ざったメールアドレス・電話番号・カード番号・パスワードらしい文字は、自動で伏せてから渡します。
- いつ・どの鍵で読まれたかは記録に残ります。要望の詳細画面の下で確認できます。
  記録には「開発者の鍵」か「GitHub Actions の鍵」かも残ります。
