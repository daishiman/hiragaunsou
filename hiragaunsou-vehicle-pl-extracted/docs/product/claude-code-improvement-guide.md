# Claude Code でこの改善要望を直す手順

対象: システム管理者（この画面を開ける人）
やること: **コピーする → 貼る** の2ステップだけです。

---

## 1. コピーする

1. アプリの管理画面で **改善要望** を開きます。
   <https://hiragaunsou-vehicle-pl.daishimanju.workers.dev/admin/improvements>
2. 直してほしい要望の左のチェック欄に印を付けます（何件でもかまいません）。
3. **「選んだものを Claude Code に渡す」** を押します。
4. 「この内容で指示文を発行します」と出ます。**「Claude Code に渡す文をそのまま読む」** を開いて、
   外に出て困る文字（お客様の名前・電話番号など）が入っていないか確かめてください。
   メールアドレスや電話番号らしいものは自動で伏せてありますが、最後に目で見るのはここだけです。
5. **「この内容で実行する」** を押します。
6. 下に **コピー用の文** が出ます。**「コピーする」** を押してください。

> この文はこの画面を閉じると二度と出せません。閉じてしまったら、もう一度4〜6をやり直してください
> （同じ要望を何度渡しても、要望が増えたり二重になったりはしません）。

1件だけ渡したいときは、要望の詳細画面にも同じ「Claude Code に渡す」があります。

---

## 2. 貼る

1. Claude Code を開きます。
2. さきほどコピーした文を、そのまま入力欄に貼り付けて送ります。
3. あとは Claude Code が要望を読み取り、順番に直していきます。

貼り付ける文には「どこを直すか」「何ができれば直ったと言えるか」まで書いてあります。
こちらから追加で説明する必要はありません。

---

## よくあること

**「この鍵は期限が切れています」と出た**
渡すための鍵は7日で切れます。管理画面で1〜6をやり直して、新しい文をコピーしてください。

**渡す相手が変わった／貼る先を間違えた**
改善要望の一覧の上にある **「Claude Code に渡した鍵を見る・止める」** から止められます。
止めた瞬間から、その文では1件も読めなくなります。

**同じ要望をもう一度渡したい**
そのまま渡し直して問題ありません。内容が変わっていない要望は「変わっていないので何もしません」と
表示され、二重にはなりません。内容を書き足していた場合だけ、新しい版として渡ります。

**渡した要望を取り下げたい**
その要望を「見送り」「誤作成」「重複」にするか、廃棄すると、渡してあった指示文は読めなくなります。

**「対応が終わっています」と出て渡せない**
すでに「対応済み」になっている要望です。もう一度直したいときは、状態を「未対応」に戻してから渡してください。

---

## 渡している中身について

- 要望の本文、どの画面か、直す場所の見当、再現手順、裏で出ていたエラー、画面の写しを渡します。
- 画面の写しは24時間だけ開けるURLで渡します。画像を他のサービスに預けることはしません。
- 送った人の氏名とメールアドレスは渡しません（直すのに要らないため）。
- 本文に混ざったメールアドレス・電話番号・カード番号・パスワードらしい文字は、自動で伏せてから渡します。
- いつ・どの鍵で読まれたかは記録に残ります。要望の詳細画面の下で確認できます。
