## 0. 最重要 — 「運送収支表」は出力であって入力ではない

業務フロー docx の STEP8 は「Excelブック『★運送収支表2025-2026_5月更新』を開き、該当月のシートに STEP7 までで作成した収支表を貼り付ける。以上で完成」と書かれている。
つまりこのブックは**本システムが最終的に組み上げる成果物**であり、ここから数字を読んで別の数字を作ってはならない。

実測した構造(見本としてのみ参照してよい範囲):

- シート構成: `2024` / `2025`(年度の全体集計)/ `対前年` / `対前年 (粗利)` / `6月収支表`〜`5月収支表`(12ヶ月分)/ `項目説明` / `5月入力確認`
- 月次シートは `★車両別収支計算用` の収支表シートと**同じ51列**。STEP8は文字どおり貼り付けであって加工ではない。
- 年度シート(`2024`/`2025`)は月ごとに 運行費・燃料費・修繕費・人件費・保険料・賦課税・運送費・一般管理費・合計・走行距離・1キロ原価・売上・1キロ売上・台数・日数・件数 の17列を集計したもの。
- `項目説明` シートには各項目の計算定義が書かれている(下の §3 の「決まり方」はここと実装を突き合わせた結果)。

本システムでの STEP8 の代替は「収支表の確定 + CSV出力」(`src/usecase/steps/confirmMonthlyPl.ts` / `exportMonthlyPlCsv.ts`)。
年度集計・対前年は `/annual` 画面が担う。**このブックを取り込んで数字の供給元にする経路は作らない。**

### 是正した箇所

`src/domain/rules/importSources.ts` の `monthly_pl_workbook` は、完成済み収支表を「答え合わせ」に使う照合専用の口で、
取り込んでも収支表の数値は1つも変わらない(コード上のコメントとテストで担保済み)。
ただし説明の `system` 欄が「★運送収支表 年度ブック」となっており、成果物を入力ソースの一覧に並べて見せていた。
実際の答え合わせ相手は STEP7 の結果である `★車両別収支計算用` の収支表シートなので、そちらを指すよう表記を直した。

## 5. 運転者マスタの出所 — 確定

**社員No と車番の対応は、`★車両別収支計算用` の収支表シートにしか存在しない。**

根拠(すべて実ファイルで確認):

1. `5給与集計表（日給者）.csv` は59列すべてを列挙したうえで、**車番を表す列を1つも持たない**。給与だけのファイルである。
2. `2026年5月売上モニタリスト.csv` は `運転者コード` と `車両コード` を両方持つが、これは**伝票1明細ごとの実績**であって割り当てではない。実測では1人が複数の車番で運行している(例: 田中久也 → 1177 / 301 / 303 / 7007)。ここから「この人の車はこれ」を一意に決めることはできない。
3. `5月収支表` シートは 車番 : コード が **1対1**(1つの社員Noが2つ以上の車番に付く行は0件)。人件費を車両に乗せるための割り当てはここで人が決めている。

したがって運転者マスタの取込元は収支表シートの `コード` `運転者名` `車番` の3列で正しい。
これは「トラクタ＋トレーラの対応表がExcelの行ラベルにしか無い」のと同種の、**Excelの体裁にしか存在しない情報**である。

補足: 1台に2人乗務している行は `658/720` のように1セルに2人分書かれる(実測1件)。取込側で1人ずつに分けて登録する。
`傭車運転手` `諸口` は自社の運転者ではないため読み飛ばす(docx STEP1のデータ整形と同じ扱い)。

## 6. ファイルの判定は列構成で行う

社内のファイル名は月ごと・将来ともに変わる前提で扱う(`5給与集計表（日給者）.csv` の先頭の `5` は月を表す)。
`src/infrastructure/parsers/detectFileType.ts` は**列見出しの組み合わせを先に見て**種別を判定し、
見出しから決まらなかったときだけファイル名のキーワードを使う。

| 種別 | 判定に使う列 |
|---|---|
| 車両別運行実績表 | `車両番号` `稼動時間` `総距離` |
| 売上モニタリスト | `車両コード` `受取運賃` `通行料` |
| 給与集計表 | `社員No` `総支給額` |

Excel からのマスタ取込も同様に、シート内の列見出しの文字で列位置を解決する(並び順に依存しない)。
対象年月はファイル名ではなく、シート1行目の「令和8年5月車両別収支表」から復元する。
