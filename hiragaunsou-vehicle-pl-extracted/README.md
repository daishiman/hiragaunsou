# 車両収支管理システム

運送会社の車両別収支をクラウド上で集計・分析し、月次入力、異常検知、赤字要因の把握を効率化するためのプロジェクトです。

## 現在の内容

- `docs/`: 要件定義、設計方針、プロジェクト資料
- `mock/`: ダッシュボードと各機能画面のHTMLモック
- `data/`: 分析元のExcelデータ
- `scripts/`: Excelデータ抽出用スクリプト
- `Product Excellence Kit/`: 設計・品質基準とテンプレート

## モックの確認

リポジトリのルートでローカルHTTPサーバーを起動します。

```bash
python3 -m http.server 8000
```

ブラウザで <http://localhost:8000/mock/> を開いてください。
