# 要件定義（要約）

## 本質的目的

運送会社の担当者が、車両ごとの月次損益を元帳票と突き合わせながら整え、赤字の理由を把握できる状態にする。

## ゴール

| ID | ゴール |
|---|---|
| G1 | 毎月の締め（取込→整形→手入力→チェック→収支表）を迷わず進められる |
| G2 | 106台規模でも数字を見比べ・直せる |
| G3 | 画面の言葉と見た目が共通で、初見でも次の一手が分かる |
| G4 | 計算の正しさは既存の計算契約を壊さない（表示の一貫性が本 feature の主眼） |

詳細は `hiragaunsou-vehicle-pl-extracted/docs/product/T1-requirements.md` を正本とする。
